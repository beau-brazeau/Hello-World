# Hello-World: Python Practice Projects

## Description
This is my first practice repository. It has two Python homework files that show basic programming, decision-making, and loops, with a business focus.

## Tools Used
- Python 3
- GitHub (for storing and sharing my work)

## Files Used
| File | What it does |
|------|--------------|
| `bbraz_hw1.py` | Four small programs: sales tax calculator, weekly pay with overtime, letter grade categorizer, and bonus eligibility checker |
| `bbraz_hw2.py` | Loan amortization calculator that finds the monthly payment and prints a month-by-month payment table |

## How to Run Program
1. Download the `.py` files from this repository.
2. Open a terminal in the folder where you saved them.
3. Run a file with:

```
python bbraz_hw1.py
python bbraz_hw2.py
```

4. Type in the values when the program asks for them.

**Example input for `bbraz_hw2.py`:** loan amount of 10000, interest rate of 5, and a term of 3 years.
